Which phones run it, and how to help

Only the Pixel 3a XL is ported. Other phones are a shortlist, chosen by SoC family and bootloader. Reports from people who test other phones go into the same matrix.

Report a phone you tested

Tried NeoSymbian on another phone, or on the Pixel? Tell us what worked. Fill in only what you know.

What you saw working

The phone, the result and the log go to the project sheet, and to a public GitHub issue if you open one. Your contact goes to the sheet only, which only maintainers can read. It is never published.

How a change gets in

Work happens in forks under the NeoSymbian org. Upstream branches stay as they are, and nothing goes back to SymbianSource.

  1. 01

    Fork

    Fork the repo under your account and branch from main.

  2. 02

    Gate

    Run the gate for that repo before you commit. The gates are listed below.

  3. 03

    Commit

    Commit only your own files. Changes to Symbian files are marked NeoSymbian.

  4. 04

    Pull request

    Open a PR against NeoSymbian/<repo>. Say what you tested, and on which phone.

  5. 05

    Review

    A maintainer merges. Kernel changes also need a QEMU or phone run.

Get in touch

Questions, a phone to lend, or something the issue tracker doesn't fit. Bugs and code questions go best in a GitHub issue.

Your message and email go to the project sheet, which only maintainers can read.
